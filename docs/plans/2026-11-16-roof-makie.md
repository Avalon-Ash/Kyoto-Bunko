# 屋頂是蒔的，不是貼的（開案書）

日期：2026-11-16。狀態：**做完並整合進 `claude/roof-1116`，尚未合併 `main`**。報告在 [`agent-runs/2026-11-16-roof-makie.md`](../agent-runs/2026-11-16-roof-makie.md)。主席審查時注意到：屋面比以前深、偏黃，簷口附近偏橄欖色；鳥居木紋放大看像斜的細紋。base：`claude/roof-1116`（`main` `d958327` 加一個文件 commit）。開案：Claude Fable 5.2（主席，不實作）。

## 1. 使用者的意見（2026-11-16，原話）

「建築的屋簷，你看起來是整片貼金。正確應該是用蒔繪方式處理，貼金都是小部分，且木胎貼金不會是完全的平整，金箔會透出木紋裡。」

（原文「蒔惠」是「蒔繪」的錯字，主席的判讀。）

## 2. 主席的理解

- **大面（屋面）是撒金粉做的**：金粉密密地蒔上去、固定、研磨。看起來是細緻的顆粒、緞面的光，高光寬而柔，有一點蒔得不勻的深淺。不是一整張鏡面的金箔。
- **貼金箔只用在小地方**：例如屋簷的邊、屋脊、塔的相輪與寶珠這類細部。
- **貼在木胎上的金箔不會完全平整**：底下的木紋會透出來，箔面有順著木理的細微起伏。
- 這段沒有文獻，是使用者的專業判斷。旁證：德川美術館「初音蒔絵文台・硯箱（部分）」的照片裡，殿舍的屋面是一大片平整的淡金，上面有細的平行線，簷口有一道亮邊，簷下是深色。屋面讀起來是粉，不是箔。

## 3. 現況（主席只讀程式確認的）

- 建築是 three.js 的網格（`architecture-mesh.js`、`frame-mesh.js`、`lantern-mesh.js`），屋面用 `MAT.gold`，簷口有一條 `MAT.silver` 的邊（`…-lip`）。
- `MAT.gold` 是 `MeshPhysicalMaterial`：`metalness: 1`，作舊後 `roughness` 約 .5，再加一張金粉法線貼圖（`flake: .22`）。在大而平的屋面上，它反射的是一整片房間與窗，所以像一張箔。
- `MAT.gold` 不只屋面在用：鳥居、燈籠、建築的框、松與楓的葉片（`stampMaterial`）也是。
- 部件材質的著色片段在 `three-renderer.js` 的 `patchMaterial`（`onBeforeCompile`），常數在 `three-pack.js` 的 `PART_LIGHT_GLSL`。

## 4. 目標

1. **屋面讀起來是金粉高蒔繪**：放大三倍看得到細顆粒；高光是寬而柔的一片，不是鏡面反射；面上有很淡的深淺不勻；往簷下與凹處漸暗（粉薄處透出底漆），要有過渡，不留硬邊。
2. **貼金只在小地方**：簷口的邊、屋脊、相輪寶珠這類。哪些部位算「貼金的小地方」由你依現有幾何判斷，報告裡列出來。
3. **貼金的地方透出木紋**：順著構件長向的細紋，法線上很淺的起伏加上極淡的明暗差。放大三倍看得出來，不放大時只是「不是鏡子」。
4. 瓦或檜皮的細線（現有的）保留，要比屋面略亮、邊緣清楚。

**做法由你決定**。提示：`MAT.gold` 的其他使用者（鳥居、燈籠、框、葉片）改成粉的質感也是對的（都是高蒔繪），可以在材質這一層統一處理；但要逐一看過，哪個變難看就單獨處理並回報。
