## 3. 觀察

### 3.0 地有三種形，不是一種

看了手箱、耳盥和塩山之後，要先分清楚三種東西。我們現在把它們全做成同一種「抬高的一塊」。

| 形 | 樣子 | 高度 | 在哪裡看到 |
|---|---|---|---|
| **洲浜**（水邊與平地） | 扁平的舌狀片，邊緣是波浪與扇貝，一片金一片銀交錯著往橫向疊 | 幾乎是平的，只有邊緣一道細稜 | 塩山蓋表的下三分之一；初音手箱的側面 |
| **土坡、遠山** | 上緣的輪廓清楚，往下用蒔暈化掉，沒有下緣 | 上緣最高，往下研到平（肉合研出） | 耳盥臺座上的遠山；比良山的山與樹下的坡 |
| **岩** | 崎嶇、直立、有孔洞，幾顆疊成一簇 | 最高（高蒔繪） | 三件都有，長在洲浜的尖端與土坡的稜上 |

- **金銀交錯是疊的主要手段**：塩山的洲浜是一片銀金貝夾在兩片金之間；初音的土坡是深灰的銀和淡金交替。靠顏色就讀得出前後，不必靠高度。
- **切金是沿著輪廓的一串**：塩山的洲浜邊緣有一排小方塊，像串珠一樣跟著輪廓走（解說寫「洲浜周縁に金切金」）。不是散在面上的短列。我們上一輪做的「沿稜的短列」散在台面上，位置不對。

### 3.1 一片土坡長什麼樣（高解析的硯箱局部）

- **小**：一片的長邊大約是蓋面寬度的十分之一到六分之一。沒有橫跨半個蓋面的單一形體。
- **輪廓崎嶇**：有尖角、凹口、扇貝狀的缺口，像舌頭或瓦片，沒有直線，也沒有平滑的長弧。
- **斷面是楔形**：堆高的只有輪廓的一側（稜），從稜往裡斜著研下去，研到和地一樣平。這就是肉合研出。所以形是靠「一道亮的稜」加「稜後面慢慢暗下去的坡」讀出來的。
- **一層壓一層**：前一片的稜壓在後一片的坡腳上，像瓦片往後疊。重疊處是最暗的地方（硫化的銀）。
- **有一側沒有邊**：坡的尾端用蒔暈化進地裡，粉漸疏，看不出輪廓在哪裡結束。
- **岩長在稜角上**：岩和土坡是一體的。岩本身也是幾片小的疊起來，有孔洞，一大帶幾小。
- **邊上有草**：細線的草葉長在稜邊與岩腳。

### 3.2 一個面的構圖（料紙箱與整套陳設）

- **疏密有一個範圍**：初音（江戶、大名婚禮調度）是滿的，山水佔一半到六成；塩山與比良山（室町）很疏，景物集中在下三分之一或一角，其餘是地。兩者都是小單元，留白的梨子地都是連續的、會流動的帶，不是被包圍起來的小洞。
- **成群**：土坡與岩 3–7 片一群，一個面有 2–4 群，群與群之間用霞、水或留白隔開。
- **走向不一定**：初音手箱的霞與地是斜著掃過去的；塩山的洲浜是水平一層層。共同點是邊緣都是波浪，沒有一條是直的。
- **建築半掩、偏一邊**：手箱蓋面的殿舍約佔面寬四分之一，在左上角，被蓋緣切掉一截；耳盥上的殿舍比較大，也是被邊緣切掉。它們被霞、樹、土坡或器物的邊遮住一部分，不在畫面正中央，也不站在一塊平台上。
- **銀佔山水的三分之一上下**：坡的陰面、水岸、霞。

### 3.3 我們現在（主席只讀程式確認的）

- `hill()`（`vocab.js`）：一條很長的帶子，上緣是正弦弧，下緣是一條直線（`foot + 26`），整條一個高度再加一個內部的小鼓包。十一區共 14 個。
- `gardenGround()`：一個多邊形整塊抬到同一個高度，四周一圈一樣的斜邊。八區各一個，是每區最大的一塊。
- 高度來自柔高度場：圖層 0 的填色經過四分之一解析度的 15 點高斯模糊（`three-pack.js` 的 `bakeSoftLayer`），所以先天就是平滑、低頻的。另有一個銳利的通道（`crisp`，著色器裡的 `cH`），現在只給很小的高度差。
- 上一輪把面換成刑部地、切金收成沿稜的短列，但「稜」在淺而平的台地上到處都是，所以切金列散在整個台面上。**皮換了，形沒有換。**

## 4. 設計

### 4.1 拆

`hill()` 與 `gardenGround()` 從各區的構圖裡拿掉。地回到梨子地。建築、樹、岩、小景原本靠平台襯托的，改由疊坡襯托。

### 4.2 新語彙：三種形，組成「一群」

一個「群」＝ 3–7 片（洲浜或土坡）加 2–5 顆岩。每一區依它的意象選用：水邊、庭、平地用洲浜；山、丘、坡道用土坡。

**洲浜**
- 扁平的舌狀片，輪廓是波浪與扇貝，長邊約 40–110 單位（蓋面寬 720），沒有直線。
- 幾乎不抬高，只有邊緣一道細稜。
- **相鄰的片金銀交錯**：淡金的片（刑部梨子地）和硫化銀的片交替，至少三分之一是銀。
- 片與片互相咬合、前後重疊，近的壓遠的。
- 切金是**沿輪廓的一串**，只放在少數幾片朝向留白的那一側。

**土坡與遠山**
- 上緣輪廓清楚（稜），有尖角與凹口；往下用蒔暈化進地裡，沒有下緣。
- 斷面是楔形：上緣最高，往下降到 0。
- 稜上金粉最密最亮，往下漸疏；稜的背光側與重疊處是硫化的銀。
- 幾片前後疊，近的稜壓在遠的坡腳上。

**岩**
- 用現有的 `rock()`（立體的高蒔繪岩），放在洲浜的尖端與土坡稜線的轉折處，一大帶一兩顆小的，腳要接在片上，不是擺在空地上。
- 岩邊可以掛現有的 `grassTufts`（它需要 `on` 指向一個部件）。

### 4.3 構圖的度

| 項目 | 範圍 |
|---|---|
| 一區的疊坡群數 | 2–4 |
| 一群的土坡片數 | 3–7 |
| 一群的岩數 | 2–5，一大帶小 |
| 單片土坡的面積 | 不超過蓋面的 4% |
| 洲浜、土坡與岩合計佔蓋面 | 20–35%（加上建築、樹、霞、水之後，山水約一半；介於初音的滿和室町的疏之間） |
| 銀的片 | 洲浜與土坡的片數裡至少三分之一 |
| 梨子地的留白 | 至少 35%，而且是連通的帶 |
| 走向 | 可斜可平，依該區的意象；任何輪廓都不能有直線 |
| 建築 | 不放大、不移動（地標要認得出來）。腳邊由一兩片土坡托住，可以被近處的一片遮住一小角 |

這些數字是主席從 §3 歸納的，不是文獻上的規定。樣板做出來不像，先改這張表。

### 4.4 架構上要解決的（做法由實作者決定）

1. **楔形的高度與銳利的稜**：現有的柔高度場做不出銳利的稜（模糊半徑太大）。需要讓稜是銳的、坡是緩的。可以加一個通道、提高解析度、或用 `crisp` 通道加漸層填色，由實作者選；選了什麼、為什麼，寫進報告。
2. **誰跟著地**：建築、樹、岩、小景都用 `groundY` 貼地（樹在上一輪剛改成逐點貼地）。地形變了，它們要跟著對，穿插偵測要是 0。
3. **會連動的場**：材質與擁有者圖（`identMaps`）、蒔暈的疏密場、遮蔽的場、刑部地的片（現在用柔高度決定疏密）、切金（現在沿柔高度的稜）、盒壁的土坡。新的形進來後都要還是對的。
4. **掛在舊部件上的小景**：有些小景的 `on` 指向舊的丘或台地的 id（例如左京的「大」字掛在 `higashiyama`）。拆掉之後要重新掛到新的土坡上，位置跟著合理的地方走。
5. **測試**：`scripts/plate.test.mjs` 裡各區部件數的圍欄要更新；`hill`／`gardenGround` 相關的行為測試依新的語彙改寫，不是刪掉了事。

## 9. 使用者可以否決的判斷

- 建築不縮小、不移動（§4.3）。初音的殿舍只有面寬的五分之一，我們的地標比較大；縮小會更像，但地標會不好認。
- 樣板選中京與伏見。

## 10. 樣板第一輪被退回（使用者 2026-11-16 看圖後，原話）

「一眼可見問題，岩放在這些位子完全不合邏輯。你自己看不應該就放過喔。尤其右上角那顆最明顯不合理。再來是形狀都是複製貼上不行，手感很重要。」（指的是 `.shots/doha/final/cmp-fushimi.png` 右半）

主席的檢討：第一輪的派工單只寫「岩放在稜線的轉折處」，沒有寫岩為什麼會在那裡；審查時也只確認「岩有站在片上」就放行。這兩點都是主席的錯。

### 10.1 岩的位置為什麼不合理（主席只讀程式與圖確認）

- 伏見的土坡是「遠山」：稜在上緣（天際線），往下化掉。岩被放在天際線上，騎在刀刃一樣的稜上，底部兩邊懸空，像一顆球擱在山尖。
- 遠山是遠的。上面一顆比山還高的岩，尺度上說不通（右上角那顆最明顯：比它腳下的山還大）。
- 每顆岩都是同一個圓錐加同一種切金格子，是另一種材質的物件「擺」上去的，不是從地裡長出來的。
- 初音硯箱的岩在哪裡：在**近景的地的前緣**（水邊、坡腳、兩片地交疊的凹處），是那片地最高、輪廓最銳的部分，後面才是平緩的坡。岩是地的一部分，一簇幾顆大小不同、互相遮擋。

### 10.2 岩的規則（修訂）

1. 岩只出現在**近景**：坡腳、水邊或洲浜的尖端、兩片地交疊的凹處、樹根旁、建築的基壇旁。**遠山的稜線（天際線）上不放岩。**
2. 每一顆岩要說得出理由。報告裡列一張表：哪一顆、靠著什麼、為什麼在那裡。說不出理由的拿掉。
3. 尺度：岩不能比它旁邊的樹高，不能比它所在的那片地的短邊寬；遠處的比近處的小。
4. 岩是地的一部分：腳要埋進坡裡或地裡（現有的 `K_ROCK_FOOT` 漸變要接得上），底部不能有任何一側懸空；岩後面要有它靠著的坡。
5. 成簇：一大帶一兩顆小的，互相遮擋、朝向不同。不是每一群都要有岩；一區的岩總數降到 4–7 顆。
6. 切金不是每顆都鋪：有的岩只有金粉與硫化銀的陰面，切金只落在少數幾顆的受光面。

### 10.3 手感：不能複製貼上

現況：`doha.js` 的 `tongueShape`／`bankShape` 是「中心、長、深、轉角、種子」的模板，每一片都是同一個形狀換一組亂數；`meshRock` 是八個點的圓，每顆岩都是同一個圓錐。稜上的摺線也是同一種放射狀直線。

修訂：
1. **每一片地的輪廓在該區的構圖檔裡逐片寫出來**（一串控制點），不是由模板加種子產生。亂數只准用在微小的抖動（不超過 1.5 單位）。
2. 一群裡要有大中小的節奏：最大的一片面積至少是最小的三倍。稜的銳度、坡的長度每片不同。
3. 稜上的摺線：拿掉規則的放射狀直線。要保留的話只留少數幾道，是彎的、長短不一。
4. **岩逐顆設計**：有矮寬的、高瘦的、斜的、裂成兩瓣的、帶凹口的。需要的話擴充 `meshRock` 接受輪廓與幾個峰的位置，不是只吃寬、高、種子。
5. 自我檢查（寫成腳本，報告附數字）：把每一片的輪廓正規化（平移、縮放、轉正）後兩兩比較，最相近的一對也要有明顯差異（定一個距離門檻並說明怎麼定的）；岩的剪影同樣比較。

### 10.4 順帶修（主席的判斷，使用者沒有提）

- 中京的洲浜太平：金的片和梨子地幾乎同色，銀的片像水窪。讓金的片明顯比地淡，並給洲浜的邊緣一點高度（稜比現在清楚），重疊處有遮蔽的暗。做法由實作者決定。
- 片與片重疊處加上遮蔽（把稜餵進遮蔽的場），只減光、不疊色。
- 伏見銀的片在日間偏亮（亮部面積 7.1 → 9.4%），收回到不高於改之前。

### 10.6 山體不能切碎（使用者 2026-11-16 追加，原話）

「另外伏見的山體不應該是切碎的。你去看其他作品參考。」

主席看了比良山蒔絵硯箱（`.shots/ref/hirasan-3.jpg` 蓋表的遠山、`hirasan-1.jpg` 蓋裏的鳥居與松）與塩山（`shioyama-2.jpg` 松山）。主席先前把「小片、崎嶇」一體套用到山上，是錯的。**小而崎嶇的是近景的坡與岩；山是一個完整的身體。**

比良山的山長這樣：
- **圓的**：三到五個圓渾的山頭前後相疊，每個山頭的稜線是一道平滑但不對稱的弧，沒有鋸齒、沒有尖角。
- **完整**：山頭之間是相連的山體，不是散開的碎片。相疊處後面的山頭被前面的遮住，只有一道細的稜線分開。
- **山腳化進霞裡**：下緣沒有輪廓，被幾道水平的霞切過去，粉漸疏。
- **山腰有樹叢**：用細線畫的一簇一簇小樹，貼著山頭的弧排，是山的紋理，也讓人知道山有多大。
- `hirasan-1.jpg`（鳥居、小祠、一棵松，站在一片安靜的地上，岸線是一道柔的曲線，岸邊幾叢草，**沒有岩**）幾乎就是伏見稻荷的題材。

伏見的修訂：
1. **稻荷山是一座山**：三到五個圓渾的山頭相疊成一個山體，橫跨千本鳥居後面。稜線平滑、每個山頭的弧不同（高低、寬窄、偏左偏右），由構圖檔逐一寫出控制點。不要鋸齒、不要放射狀摺線。
2. 山頭之間金銀交替可以保留，但要含蓄：以金為主，後面的山頭或背光的一側才是硫化的銀。不要一片亮銀一片金地切開。
3. 山腳用蒔暈化掉，可以讓現有的霞（`suyari`）切過山腰。
4. 山腰可以加少量細線的樹叢（平嵌的線，貼著稜線排），不是必須。
5. **山上不放岩。** 岩只在近景：鳥居的腳邊、狐的石座旁、樓門前，總數 3–5 顆，依 §10.2。
6. 近景（樓門與鳥居站的地）是一片安靜的地，岸線柔，不要碎。

這也修正 §3.1 與 §4.2：「輪廓崎嶇、小片」只適用於近景的坡與洲浜；遠山是完整、圓渾、相疊的山體。

### 10.7 遠山蒔繪是定型的技法（使用者 2026-11-16 追加）

使用者：「遠山蒔繪是一種專門技法，呈現很一致。你可以關鍵字去找。」

查到的（查核日 2026-11-16）：
- **遠山文**是定型的紋樣：「遠く連なる山並みを、なだらかな曲線で表した文様」「霞の向こうに重なる山々」（[淡交社 TANKO＋：遠山文](https://tankoplus.jp/sado/article-146/)）。
- 技法上是**暈著蒔**：「近景はやや高く盛り上げ、遠景は非常に細かい金粉を暈しながら蒔く」（[皇居三の丸尚蔵館：妙法山遠望図蒔絵巻莨箱](https://collection.shozokan.nich.go.jp/object/SZK003785)）。
- 作例（茶道具的「遠山蒔絵棗」兩件，圖在 `.shots/ref/_sheet-toyama.png`、`toyama-natsume-*.jpg`）：[岡澤起幸 遠山蒔絵大棗](https://www.ryokuwado.com/item/41367/)（「遠方の山々の稜線を望むように」）、[中村宗悦 中棗 遠山蒔絵](https://taikando.shop-pro.jp/?pid=128693437)。兩件是現代的作品，黑漆地；我們是金的梨子地，要自己轉譯。
- 比良山蒔絵硯箱（室町）蓋表的遠山是同一種畫法，多了山腰的樹叢。

兩件作例和比良山呈現一致，歸納成規則：

1. **三到五座山相疊**，每座是一道平緩的曲線：一個主峰加一兩個肩，左右不對稱。沒有鋸齒、沒有尖角、沒有摺線。
2. **稜線是唯一的硬邊**。金粉在稜線最密最亮，往下均勻地暈開、漸疏，到山腳完全化進地裡。
3. **前山的亮稜壓在後山暈掉的山腳上**。遠近就是靠這個明暗對比讀出來的，不靠高度、不靠輪廓線。
4. **平的**：研出，沒有隆起（或極淺）。這和近景的高蒔繪相反：近景盛高，遠景平而細。
5. **粉很細**：山體裡沒有刑部的大片、沒有切金、沒有任何紋理，只有細粉的疏密。
6. **每座山的金略有不同**：有的偏金、有的偏青金（淡而冷）、有的較暗，但都是同一個色系，不是一金一銀切開。
7. 山上沒有岩。要加東西的話只有比良山那種細線的樹叢，貼著稜線。

伏見的稻荷山照這七條做。這取代 §10.6 第 1–4 點裡和它不一致的部分（特別是：山體裡不要刑部地的片、不要硫化銀的整片、不要隆起的稜）。在金的梨子地上要讓「暈」讀得出來，山體的金粉要比地明顯淡而細（青金到淡金），山腳暈回地的梨子地。

### 10.8 遠山要用肉合研出（使用者 2026-11-16 確認並附收藏照片）

使用者：「對，所以要用肉合研出方式處理，給你看我收藏。」附三張照片（朱漆的盃，遠山與若松），存在 `.shots/ref/user-toyama-closeup.png`、`user-toyama-cup-a.png`、`user-toyama-cup-b.png`（不提交）。**這三張是遠山這個題材最權威的參考，優先於主席找到的兩件棗。**

這修正 §10.7 的第 4 條（主席寫成「平的、沒有隆起」是錯的）。照片裡看得到的：

1. **稜是盛起來的**。特寫裡前山的稜邊有一道細的台階，壓在後山上，台階下有一道很細的暗線（是高低差的影子，不是畫的）。從稜往下，面是斜著研下去的，研到和地一樣平。這就是肉合研出：只有稜的那一線是高的，面是緩坡。
2. **山是大而圓的**。一座山就是一個飽滿的圓弧，佔盃面的三分之一到一半，輪廓簡單、平滑、略不對稱。兩三座前後相疊。「小而崎嶇」完全不適用。
3. **金粉沿稜最密，往下暈開**，到山腳露出地的朱色。粉很細、很勻，表面是緞面的光，沒有顆粒感的大片。
4. **有一座山用不同的金屬**（照片右下角那座偏灰，是銀或青金），當作變化，不是一金一銀交錯。
5. **若松**：山坡上散著幾棵小松，用細線畫的（付描），針葉一根一根，葉簇的根部有深色的點。大小不一、朝向略不同，有的站在稜的後面、只露出上半。
6. **草點**：松的腳邊與坡上有三四筆一組的短點，很小、很疏。
7. **谷間有流水**：兩座山之間有一束細的平行線。
8. 山上沒有岩。

伏見的稻荷山照這八條做：
- 三到五座大而圓的山相疊，稜盛起（用上一輪做出來的「銳利的稜加往下降到 0 的楔」，但輪廓改成平滑的圓弧，一座山一個弧），面是細粉的暈，山腳化進梨子地。
- 稜下的暗線由高低差與遮蔽產生，不要畫。
- 一座山用硫化的銀或青金，其餘是金。
- 山坡上加 5–9 棵細線的若松與幾組草點（平嵌的線；松可以借用或簡化現有的松的語彙，但要是細線、小、平的，不是現有那種立體的大松）。谷間的流水非必須。
- 山體裡不用刑部的大片、不用切金。
