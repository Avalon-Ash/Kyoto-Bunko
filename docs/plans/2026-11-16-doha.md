## 3. 觀察

### 3.0 地有三種形，不是一種

看了手箱、耳盥和塩山之後，要先分清楚三種東西。我們現在把它們全做成同一種「抬高的一塊」。

| 形 | 樣子 | 高度 | 在哪裡看到 |
|---|---|---|---|
| **洲浜**（水邊與平地） | 扁平的舌狀片，邊緣是波浪與扇貝，一片金一片銀交錯著往橫向疊 | 幾乎是平的，只有邊緣一道細稜 | 塩山蓋表的下三分之一；初音手箱的側面 |
| **土坡、遠山** | 上緣的輪廓清楚，往下用蒔暈化掉，沒有下緣 | 上緣最高，往下研到平（肉合研出） | 耳盥臺座上的遠山；比良山的山與樹下的坡 |
| **岩** | 崎嶇、直立、有孔洞，幾顆疊成一簇 | 最高（高蒔繪） | 三件都有，長在洲浜的尖端與土坡的稜上 |

- **金銀交錯是疊的主要手段**：塩山的洲浜是一片銀金貝夾在兩片金之間；初音的土坡是深灰的銀和淡金交替。靠顏色就讀得出前後，不必靠高度。
- **切金是沿著輪廓的一串**：塩山的洲浜邊緣有一排小方塊，像串珠一樣跟著輪廓走（解說寫「洲浜周縁に金切金」）。不是散在面上的短列。我們上一輪做的「沿稜的短列」散在台面上，位置不對。

### 3.1 一片土坡長什麼樣（高解析的硯箱局部）

- **小**：一片的長邊大約是蓋面寬度的十分之一到六分之一。沒有橫跨半個蓋面的單一形體。
- **輪廓崎嶇**：有尖角、凹口、扇貝狀的缺口，像舌頭或瓦片，沒有直線，也沒有平滑的長弧。
- **斷面是楔形**：堆高的只有輪廓的一側（稜），從稜往裡斜著研下去，研到和地一樣平。這就是肉合研出。所以形是靠「一道亮的稜」加「稜後面慢慢暗下去的坡」讀出來的。
- **一層壓一層**：前一片的稜壓在後一片的坡腳上，像瓦片往後疊。重疊處是最暗的地方（硫化的銀）。
- **有一側沒有邊**：坡的尾端用蒔暈化進地裡，粉漸疏，看不出輪廓在哪裡結束。
- **岩長在稜角上**：岩和土坡是一體的。岩本身也是幾片小的疊起來，有孔洞，一大帶幾小。
- **邊上有草**：細線的草葉長在稜邊與岩腳。

### 3.2 一個面的構圖（料紙箱與整套陳設）

- **疏密有一個範圍**：初音（江戶、大名婚禮調度）是滿的，山水佔一半到六成；塩山與比良山（室町）很疏，景物集中在下三分之一或一角，其餘是地。兩者都是小單元，留白的梨子地都是連續的、會流動的帶，不是被包圍起來的小洞。
- **成群**：土坡與岩 3–7 片一群，一個面有 2–4 群，群與群之間用霞、水或留白隔開。
- **走向不一定**：初音手箱的霞與地是斜著掃過去的；塩山的洲浜是水平一層層。共同點是邊緣都是波浪，沒有一條是直的。
- **建築半掩、偏一邊**：手箱蓋面的殿舍約佔面寬四分之一，在左上角，被蓋緣切掉一截；耳盥上的殿舍比較大，也是被邊緣切掉。它們被霞、樹、土坡或器物的邊遮住一部分，不在畫面正中央，也不站在一塊平台上。
- **銀佔山水的三分之一上下**：坡的陰面、水岸、霞。

### 3.3 我們現在（主席只讀程式確認的）

- `hill()`（`vocab.js`）：一條很長的帶子，上緣是正弦弧，下緣是一條直線（`foot + 26`），整條一個高度再加一個內部的小鼓包。十一區共 14 個。
- `gardenGround()`：一個多邊形整塊抬到同一個高度，四周一圈一樣的斜邊。八區各一個，是每區最大的一塊。
- 高度來自柔高度場：圖層 0 的填色經過四分之一解析度的 15 點高斯模糊（`three-pack.js` 的 `bakeSoftLayer`），所以先天就是平滑、低頻的。另有一個銳利的通道（`crisp`，著色器裡的 `cH`），現在只給很小的高度差。
- 上一輪把面換成刑部地、切金收成沿稜的短列，但「稜」在淺而平的台地上到處都是，所以切金列散在整個台面上。**皮換了，形沒有換。**

## 4. 設計

### 4.1 拆

`hill()` 與 `gardenGround()` 從各區的構圖裡拿掉。地回到梨子地。建築、樹、岩、小景原本靠平台襯托的，改由疊坡襯托。

### 4.2 新語彙：三種形，組成「一群」

一個「群」＝ 3–7 片（洲浜或土坡）加 2–5 顆岩。每一區依它的意象選用：水邊、庭、平地用洲浜；山、丘、坡道用土坡。

**洲浜**
- 扁平的舌狀片，輪廓是波浪與扇貝，長邊約 40–110 單位（蓋面寬 720），沒有直線。
- 幾乎不抬高，只有邊緣一道細稜。
- **相鄰的片金銀交錯**：淡金的片（刑部梨子地）和硫化銀的片交替，至少三分之一是銀。
- 片與片互相咬合、前後重疊，近的壓遠的。
- 切金是**沿輪廓的一串**，只放在少數幾片朝向留白的那一側。

**土坡與遠山**
- 上緣輪廓清楚（稜），有尖角與凹口；往下用蒔暈化進地裡，沒有下緣。
- 斷面是楔形：上緣最高，往下降到 0。
- 稜上金粉最密最亮，往下漸疏；稜的背光側與重疊處是硫化的銀。
- 幾片前後疊，近的稜壓在遠的坡腳上。

**岩**
- 用現有的 `rock()`（立體的高蒔繪岩），放在洲浜的尖端與土坡稜線的轉折處，一大帶一兩顆小的，腳要接在片上，不是擺在空地上。
- 岩邊可以掛現有的 `grassTufts`（它需要 `on` 指向一個部件）。

### 4.3 構圖的度

| 項目 | 範圍 |
|---|---|
| 一區的疊坡群數 | 2–4 |
| 一群的土坡片數 | 3–7 |
| 一群的岩數 | 2–5，一大帶小 |
| 單片土坡的面積 | 不超過蓋面的 4% |
| 洲浜、土坡與岩合計佔蓋面 | 20–35%（加上建築、樹、霞、水之後，山水約一半；介於初音的滿和室町的疏之間） |
| 銀的片 | 洲浜與土坡的片數裡至少三分之一 |
| 梨子地的留白 | 至少 35%，而且是連通的帶 |
| 走向 | 可斜可平，依該區的意象；任何輪廓都不能有直線 |
| 建築 | 不放大、不移動（地標要認得出來）。腳邊由一兩片土坡托住，可以被近處的一片遮住一小角 |

這些數字是主席從 §3 歸納的，不是文獻上的規定。樣板做出來不像，先改這張表。

### 4.4 架構上要解決的（做法由實作者決定）

1. **楔形的高度與銳利的稜**：現有的柔高度場做不出銳利的稜（模糊半徑太大）。需要讓稜是銳的、坡是緩的。可以加一個通道、提高解析度、或用 `crisp` 通道加漸層填色，由實作者選；選了什麼、為什麼，寫進報告。
2. **誰跟著地**：建築、樹、岩、小景都用 `groundY` 貼地（樹在上一輪剛改成逐點貼地）。地形變了，它們要跟著對，穿插偵測要是 0。
3. **會連動的場**：材質與擁有者圖（`identMaps`）、蒔暈的疏密場、遮蔽的場、刑部地的片（現在用柔高度決定疏密）、切金（現在沿柔高度的稜）、盒壁的土坡。新的形進來後都要還是對的。
4. **掛在舊部件上的小景**：有些小景的 `on` 指向舊的丘或台地的 id（例如左京的「大」字掛在 `higashiyama`）。拆掉之後要重新掛到新的土坡上，位置跟著合理的地方走。
5. **測試**：`scripts/plate.test.mjs` 裡各區部件數的圍欄要更新；`hill`／`gardenGround` 相關的行為測試依新的語彙改寫，不是刪掉了事。

## 9. 使用者可以否決的判斷

- 建築不縮小、不移動（§4.3）。初音的殿舍只有面寬的五分之一，我們的地標比較大；縮小會更像，但地標會不好認。
- 樣板選中京與伏見。
- 建築維持在現在的位置、不被邊緣切掉。初音的殿舍是偏一邊、被切掉一截的；我們的地標要完整才認得出來。
- §4.3 的數字。
