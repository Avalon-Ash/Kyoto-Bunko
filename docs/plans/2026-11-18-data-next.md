## 2. 規則（開工前先讀；全文在 `AGENTS.md` §2 與 `docs/DEVELOPMENT.md`）

- **真實性第一**：查不到可靠來源就退役（從 schema 與中日 locale 一起刪）；寧可刪一句或退役一筆，也不留沒有來源的說法。這類判斷主代理直接做，不逐筆問使用者。
- **ID**：退役後不重編號；新增的 ID 一律用歷史上沒用過的號碼（`git log -p -- src/data/spots` 找最大號）。
- **座標**：國寶與鄰近市町的景點要有座標，取自 Wikidata；不知道就不填，不用假座標消警告。
- **「國寶」標籤**含國寶建造物與國寶美術工藝品。
- 食處照 `docs/DEVELOPMENT.md` 的 Tabelog 查核要求。**Tabelog 跳 Cloudflare 驗證時不要繞過**，列為未確認。
- 受保護檔案（`src/data/tags.ts`、`types.ts`、`areas.ts`、`wards.ts`、`index.ts`、`src/types.ts`）不改。
- 每次改完跑四項：`npm run lint`、`npx --no-install tsx validate_data.js --strict`（ERROR 0、WARN 不增加）、`npm test`、`npm run build`。
- 合併 `main` 與 `git push` 要使用者同意，分開問。
