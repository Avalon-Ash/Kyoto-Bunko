## 2. 問題

各個材質分開算：地是自寫的著色器，岩、屋頂、樹、平嵌、盒體各有各的色溫、清漆量與反光。放在一起像不同來源的零件。three.js r186 的清漆層沒有顏色，`attenuationColor`／`thickness` 只作用在透射（研究備忘錄已在原始碼確認），所以內建材質做不出有色的透漆。

## 3. 要做的

**一層共用的透漆，寫在材質裡**（不是螢幕濾鏡）：

1. **吸收**：光進去、出來各穿過透漆一次。依視線與光線在膜裡的路徑長做吸收（Beer-Lambert）：膜越厚、看得越斜，底下的顏色越深、越暖（琥珀）。只乘在底層的貢獻上，不乘在漆面本身的反光上。
2. **厚薄跟著形走**：凹處、物件腳邊、片與片之間積得厚；稜與凸面磨得薄。厚度用現有的場來定（地：柔高度與接觸場；立體部件：離地高度 `vLift`、法線朝向）。盛起的部分也罩，只是薄。
3. **共用的漆面反光**：所有表面最上面是同一組漆面參數（同一個粗糙度、同一個菲涅耳），底下才是各自的金、銀、貝、珊瑚。現在各材質各設各的 `clearcoat`，改成共用。
4. **範圍**：地、盒壁與蓋沿、立體部件（建築、岩、狐、燈籠等）、樹的幹與葉、霞。紙背景不罩。
5. **不能做的**：不能改變三層亮度的順序與差距（`2026-11-16-ground-tone.md` §3）。包漿動的是色溫與表面，不是把東西壓暗。銀在包漿下帶一點暖，但仍然是淡的。

**開關與強度**：網址參數 `?coat=0..1`。**這一包預設是 0（關）**，所以線上畫面與降級圖都不變；`?coat=1` 是完整強度。強度另外乘上作舊程度 `uAge`。使用者看過、定了強度之後，下一包才把預設打開並重拍降級圖。

## 4. 驗收（在南區做，另抽伏見與上京各一張確認沒有壞）

**先拍 `?coat=0` 的圖當對照。**

**畫面**（`.shots/coat/`，不提交）：
- 南區不放大：`coat=0`、`coat=.5`、`coat=1` 三張並排，日與夜各一組。
- 南區放大兩倍，游標光停在兩個不同的位置（盒子會跟著傾斜），`coat=1`：要看得出斜的那一側比正的那一側更深更暖。和 `coat=0` 同位置的圖並排。
- 放大三倍看一處「金的屋面、銀的簷口、岩、地」同框的地方：四種材質在 `coat=1` 下是不是像罩在同一層膜裡。
- 伏見、上京各一張 `coat=1` 不放大。手機 375 一張 `coat=1`。
- 報告裡對每張寫看到什麼：有沒有變髒或變糊、哪個材質被染得太過、銀還淡不淡、珊瑚與青貝還認不認得出。

**數字**：
- `PLATE_TONE=1`：`coat=1` 時三層的亮度中位數，和 `coat=0` 比，地、濃梨子地、圖案之間的差距變化不超過 3；每層自己的變化不超過 5。
- 各層的平均色相與彩度在 `coat=0` 與 `coat=1` 的變化（量法自己定，報告附指令）：預期整體往暖偏、材質之間的色相差縮小。
- 效能：375×812、`PLATE_CPU=4`，`coat=1` 的換函最長幀與閒置幀時間不比 `coat=0` 多 10% 以上。
- `coat=0` 的畫面要和改之前逐像素一致（會動的霞與流水除外）。

**例行**：`npm run lint`、`npx --no-install tsx validate_data.js --strict`、`npm test`、`npm run build`；穿插 0。降級圖不重拍（預設是關）。
