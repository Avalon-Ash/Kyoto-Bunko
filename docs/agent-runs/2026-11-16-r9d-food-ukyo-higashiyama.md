## 5. 方法與限制

- 搜尋：WebFetch 取 Tabelog 英文版搜尋頁（`https://tabelog.com/en/kyoto/rstLst/?sw=<店名>`），再取各店詳情頁讀地址、電話、狀態標示、近期評論造訪月；WebSearch 補第二來源（rurubu、TableCheck、zaikei、autoreserve、aumo）。
- 日文版 Tabelog 與 curl 本次未嘗試（上一批已知回 403），只用英文版。
- 搜尋踩到的坑：UK-049 用「竹仙 嵯峨」、UK-069 用「平野屋 嵯峨」、UK-084 用「Kew 龍安寺」皆 0 筆，改單獨關鍵字（「竹仙」「平野屋」「Kew」）才搜到；HY-065、066、067 加「祇園」或「親子丼」也 0 筆，改單獨關鍵字。
- HY-067（閉店）、HY-065（臨時休業）依賴 Tabelog 單一來源，其他網站沒有交叉資訊。
- 評論日期是造訪月份，且詳情頁只讀到精選 3 則，不代表全部最新評論。UK-075、UK-077、UK-080、HY-076 的精選評論偏舊（2025 年或更早），但無閉店標示，仍判營業中。
- 未使用 Google Maps、官方社群（Instagram）：網路工具讀不到動態頁面。
- 本機只用 Bash 讀 schema 與 locale 做出 52 筆清單，腳本沒有放進 repo。
