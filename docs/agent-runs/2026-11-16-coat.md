## 做法
- **吸收**：`T = exp(-A · 厚 · ½(1/cosθt_v + 1/cosθt_l) · uCoatK) · 1.17`，`A = -ln C`，`C = (.96,.80,.50)`（垂直進出兩次、厚 1 的殘色），`cosθt = sqrt(1-(1-cos²θ)/1.5²)`，v 為視線、l 為主光。1.17 是補償，讓亮度中位數不降。`uCoatK = coat × uAge`。
- **只乘底層**：立體部件與樹在 `aomap_fragment` 乘 `reflectedLight` 四項（漆面 clearcoat 在其後另加，不被乘）。地、盒壁、霞走自寫著色器，在 `mFinish` 乘 T 後加回 `mCoat()·(1-T)·.3`（漆面反光的保留）。
- **厚度**：地 `(.55+.8·occ+.55·(1-smoothstep(0,.3,hs)))·(.85+.3·noise)`（occ=接觸場，hs=柔高度）；盒壁 `.9+.7·low`（越靠腳越厚）；立體部件與樹 `mix(1.5,.7,smoothstep(0,16,vLift))·(.75+.5·(1-朝上))`（腳邊厚、頂面薄）；盒的蓋沿、內壁、緣、托盤沒有 vLift，用固定 lift=8。
- **共用漆面**：`coat>0` 時，除 paper、cord、發光件外，clearcoat 至少 `.32·coat`；原本 clearcoat ≤ .6 者的粗糙度往 .1 靠。鏡面型（黑漆、水、青貝，clearcoat 1）不動。
- **接上**：地（含蓋沿）、盒壁、霞（mist）、全部立體部件（屋頂、岩、狐、燈籠、黑漆、葉貼金）、盒的蓋沿／內壁／緣／托盤、樹幹與樹葉。**沒接**：紙、繩、發光自發光項、背景。
- **預設關**：`coat=0` 不編入任何透漆程式（`#define` 與注入都不產生），程式快取鍵不變。

## 邊的那一圈怎麼做
- 地上平嵌、水、霞、坡：在輪廓內側取半徑 r 的六個取樣（`mEdgeOut`），數有幾個落在形外，`ke = smoothstep(0, .4, 比例)`；邊上 ke≈1，往內到 r 處為 0，沒有台階。r = (0.6 + 0.5·uAge)·(0.75..1.25 的雜訊)·(0.8+0.4·膜厚)，作舊 .85 時約 0.85–1.5 單位（一圈由濃到無，最濃約在 0.3 單位內）。
- 坡（2–4、19–24）用柔高度或 `fine.g` 的底端：`1-smoothstep(.01,.14,hs)`（遠山再乘 .6，不然像描邊）。
- 吸收：`exp(-(-ln C_edge)·膜厚·路徑)`，最濃處把亮色乘成 (.50,.28,.10)。面本色、不加影子、不加台階。
- 邊上原本的亮邊（斜面高光）被同樣乘暗；沒有改法線。
- 開關：`?coat=0` 關；預設 `COAT_DEFAULT = 1`。dev 用 `?dens=coat` 看三類權重（紅沉、綠邊、藍薄膜）。dev 的遮罩視圖不受包漿影響（否則量測會被染色）。

## 預設強度
採用 **1.0**，預設打開。理由：三層亮度、效能的驗證都在 1.0 做；`uCoatK = coat × uAge`，作舊為 .85。
