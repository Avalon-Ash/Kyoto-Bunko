## 7. 使用的指令與搜尋方式

- 清單：`grep T_FOOD src/data/spots/{kita,nishikyo,fushimi,kamigyo}.ts`，用 id 對 `src/data/locales/{ja,zh}/<區>.ts` 取名稱與描述；輸出寫在 scratchpad，不入 repo。
- Tabelog：WebFetch 取 `https://tabelog.com/en/kyoto/rstLst/?vs=1&sw=<店名>`（英文版搜尋頁；日文版與 curl 同上批回 403），再抓需要的詳情頁讀地址、電話、開業日、評論日期與「Closed／Listing on hold」標示。同名分店以最近車站、Tabelog 區碼（A260503 北、A260401/A260403 西京、A260601 伏見、A260501/A260202/A260302 上京）與詳情頁地址區分。
- 網搜（WebSearch）用於 NS-083、KG-074、KG-019、KG-077、FS-051、FS-065 與國寶複查；二手來源只當線索。
- 國寶：WebFetch 取 ja.wikipedia 各寺條目、`https://online.bunka.go.jp/heritages/detail/126217`（大覚寺御手印遺告）、天龍寺官網。
- 抓不到／無效：`kunishitei.bunka.go.jp` 搜尋頁（404）；`online.bunka.go.jp` 搜尋頁（JS 載入，回無關結果）；毘沙門堂官網 bishamondo.com（同名無關網站）；ja.wikipedia「京都府の国宝一覧」（404）、「日本の国宝一覧」（過長只讀到約 2/3）。
