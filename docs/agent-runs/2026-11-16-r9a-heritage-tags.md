## 2. 判定依據（規則）

- 世界遺產：以「古都京都の文化財」17 處構成資產為準（下鴨神社、東寺、延曆寺、平等院、二條城、龍安寺、賀茂別雷神社、清水寺、醍醐寺、仁和寺、宇治上神社、高山寺、西芳寺、天龍寺、鹿苑寺、慈照寺、西本願寺）。
- 國寶：分四種——建造物國寶、藏有國寶（美術工藝品，含寄託於博物館但所有者為該寺）、只有重要文化財、查無。前兩種判為正確。
- 國寶標籤的「藏有」判定：建仁寺、相國寺、永觀堂屬此類，建議保留，但若專案想把標籤限縮成「可在當地見到國寶」，建仁寺（原本寄託京都國立博物館，寺內為複製）與相國寺（國寶在承天閣美術館展出，並非常設）請主席另行裁決。

## 8. 使用的指令與搜尋方式

- 清單：`npx --no-install tsx <scratchpad>/list.mts`（讀 `src/data/spots/*.ts` 區塊，以 `tagIds` 判定含 `世界遺產`／`國寶`，輸出 id、區、類型、標籤數）；名稱以 `grep -h "'<id>'" src/data/locales/{ja,zh}/*.ts` 取得。腳本放 scratchpad，未放入 repo。
- 校驗：`grep -c "世界遺產" src/data/spots/*.ts` 與腳本結果一致。
- 宇治範圍：`grep -rn "宇治\|Uji" src/data/wards.ts src/data/municipalities.ts` 無結果。
- 網路：WebSearch／WebFetch。文化廳資料庫 kunishitei.bunka.go.jp 動態檢索與 ja.wikipedia 一覽頁無法抓取（404／403／PDF 字型無法萃取），改以文化遺產線上（online.bunka.go.jp）個別條目、京都市官方資料、各寺社與旅遊資料交叉；維基僅作線索。
- 每個景點最多兩輪搜尋；一輪無可靠來源再補第二輪，仍無者列未確認。
- 限制：多數結論來自搜尋摘要而非逐頁閱讀原始資料庫畫面；「中」與「中高」可靠度者已標示。
