指令：`node scripts/plate-shot.mjs <outDir> <job…>`（`PLATE_LIGHT=0.97,0.03`，1440×900，不放大；放大張加 `PLATE_CENTER=1`）。修前修後並排：`.shots/nine/{nishikyo,kamigyo,shimogyo}/3-before-after-{day,night}.png`；放大：`3-zoom-shore.png`（西京、下京）、`3-zoom-outside.png`（上京）。十一區總覽：`.shots/nine/overview-day.png`、`overview-night.png`（每格標區名，同視窗大小、不放大）。
