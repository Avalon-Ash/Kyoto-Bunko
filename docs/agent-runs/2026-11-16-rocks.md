## §15.1 逐條

1. 大：主岩寬 36–48（30–50 內）；伴岩約主岩的 25–35%（略小於「三分之一到一半」）。高度 18–23；旁邊的松 100–112、樓門屋面 13.5：高度是松的約兩成，**沒到「四成到七成」**；高於屋面。岩比樹矮、不比所在地寬。部分做到。
2. 崎嶇有層次：3–5 塊相疊、2–3 峰、有凹口（grooves）。沒有孔洞。做到（孔洞沒做）。
3. 盛得高、折面：平面著色的折面，塊間是折；比所有建築以外的浮雕高。放大三倍看得出折面，但是「垂直槽紋」的結晶感，不像初音圓渾的疊塊。部分做到。
4. 色：青金（淡橄欖）、金、淡銀混著，每簇兩種以上。部分做到：橄欖偏黃綠，沒有初音那種深色陰面。
5. 細線：5–6 道，淡金。在銀面上看得到；在青金面上對比不夠。部分做到。
6. 切金：2 組（romon-step 2×3、karamon-foot 3×2）；放大三倍都看不清楚。
7. 卵石：每簇 3–4 顆，扁、銀或青金。做到。
8. 位置與數量：都貼著靠的東西，伏見 3 簇、中京 3 簇；穿插 0。做到。
