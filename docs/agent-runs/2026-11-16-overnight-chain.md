## 4. 問題與沒做到的

- **使用者還沒在實機上看過本輪任何畫面改動。** 所有截圖都是無頭 Chrome 加桌機 GPU。
- 鳳凰：放大三倍認得出是展翅的鳥；不放大時頭與喙只有幾像素，台座讀成一塊淺色方塊（CONFIRMED）。
- 小景：草、葦、「大」字不放大時幾乎看不到；上京東松旁的草放大也幾乎看不見（CONFIRMED）。平嵌圖案約每單位 1 像素，細線要 2.4 單位以上；貼地的屋形與瀑會被視角壓扁。
- `parts.js` 的 `act()` 會讓 `MAT.lamp` 的部件在游標停留時發橘光：讀程式確認，沒有在瀏覽器實測；小景已不使用 `MAT.lamp`（PLAUSIBLE）。
- 中京的石垣共用岩的著色器，外觀跟著 R4 變了，沒有專門看過（PLAUSIBLE）。
- R8：實機的捲動手勢是否誤觸按壓回饋未驗；地圖面板裡的卡片也會傾斜，未逐一看。R8b：補批完成前（約 0.5 秒）頁內搜尋找不到未渲染的卡片；冷啟動第一次進詳細頁仍有一幀 200 ms。
- 背景霞帶避開盒子的輪廓（`backdrop.js` 的 `CABINET_SILHOUETTE`）是照舊盒子調的，比 three 的盒子窄 2–10 px；`scripts/ui-renewal.test.mjs` 的斷言只涵蓋蓋頂與各區網格。
- 資料：「營業中」只代表 Tabelog 英文版沒有閉店類標示；天龍寺的「國寶」是依「查無」移除，文化廳資料庫的檢索頁抓不到。12 月複查 HY-065、NK-120、NK-111。
