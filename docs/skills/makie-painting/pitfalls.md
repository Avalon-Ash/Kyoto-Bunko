# 踩過的坑

Kyoto Bunko 2026-11-13～17。每條：發生了什麼 → 為什麼錯 → 之後怎麼做。標記見 [sources.md](sources.md)。

## A. 畫法的坑

| # | 發生了什麼 | 為什麼錯 | 之後怎麼做 | 來源 |
|---|---|---|---|---|
| A1 | 拿整張參考照片的亮度中位數（50–53）當地的目標，地被調成圖案該有的亮度，山與岸只剩一條輪廓線 | 那是地與圖混在一起的數字 | 分層量：地、濃梨子地、圖案各自的中位數，守住順序 | 案:ground-tone §2；記:hatsune-is-technique-benchmark |
| A2 | 在岩與建築腳邊往地上混一圈暗色和一條暗線當「積汙」 | 均勻、有邊，看起來是人畫的；【原話】「太工整看起來很刻意突兀」 | 深度改用遮蔽只減環境光；任何相接都給漸變 | 記:plate-light-not-paint；案:patina 修訂 |
| A3 | 照初音蓋面把岩越做越低、越圓、越扁（圓錐 → 鼓包 → 水晶簇 → 饅頭 → 厚板），五輪都不對 | 把正視構圖的高蒔繪厚度讀成了俯瞰的體積；【原話】「妳松就有對喔。我猜妳是被厚度騙了。」 | 照片裡的輪廓就是立面輪廓，直接照畫；發現自己在把東西做扁做圓就停 | 記:plate-objects-are-elevation-pictures；案:doha §18 |
| A4 | 岩派給子代理六輪；「細修」的派工單列了六項造型改動，子代理把模型整個換成角錐，比起點差 | 派工單等於要求改造型；看圖判斷在主代理，派出去成品只有實作者的水準 | 細修就只寫細修；造型的判斷自己做；不採用的版本還原到使用者指定的那一版 | 案:doha §18.1–18.2 |
| A5 | 楓畫成一根棍子頂三片巨大楓葉 | 為了保住葉形把特徵放大，樹不像樹 | 立體只做普通的樹形，楓葉用切金銀落滿地表現（形歸形、意歸意） | 記:plate-form-vs-imagery |
| A6 | 為了留白率在空地隨機撒草、松、梅、籬，每區都一樣的遠山和雲 | 【原話】「地現在是無差別亂塞，把原來的物、形意破壞了。」 | 小景依附於物、寫進構圖資料；留白率只當參考 | MCP §7 |
| A7 | 把「小片、崎嶇」一體套到山上，山被切成一片片鋸齒；岩擺在遠山的稜線上、比山還大 | 小而崎嶇只屬於近景；遠山是一個完整的身體 | 遠山三到五座大而圓相疊；岩只在近景 | 案:doha §10、§10.6 |
| A8 | 遠山寫成「平的、沒有隆起」；接著又把使用者盃上的若松、草點抄進規則 | 遠山是肉合研出（稜盛起）；那件盃是明治的，意匠不同 | 參考圖先分技法與意匠、年代；只取技法 | 案:doha §10.8–10.9 |
| A9 | 把研出蒔繪與平文整片歸成「漆下、染重」 | 研出的面是露出來的本色，只有輪廓內側一圈包在漆下 | 照 techniques §1 的四類分 | 案:coat §7.4 |
| A10 | 把「所有材質的色相差縮小」當包漿的目標 | 色相統一是漆下那一組的性質；漆上與漆下之間本來就該有差 | 分組量色相差 | 案:coat §7.2 |
| A11 | 照一件江戶櫛的實物提議把小片的銀改黑、做平文脫落 | 那是保存不良的損傷；【原話】「全部維持淡」 | 作舊的標準是保存良好的傳世品 | 案:technique-stack §8 |
| A12 | 把梨子地的金粉縮到接近像素級 | 方向和使用者的「初音的金粉更大、濃密、色多」相反 | 片大、不規則、多色，暗來自片間的漆 | MTP §2a；案:ground-tone §1 |
| A13 | 大面積的高台、庭整面鋪 45 度菱形切金 | 日本沒有這種用法；切金是點睛 | 大面積用刑部梨子地、平目地；切金成群在邊緣 | 案:technique-stack §1–§4 |
| A14 | 屋面一整片鏡面金屬，反射整個房間，像一張箔 | 大面是撒粉的高蒔繪；貼金只在小地方 | 粉的顆粒、寬柔的高光；貼金透木紋 | 案:roof-makie |
| A15 | 平嵌的落葉旁有一圈像融化的蠟 | 輪廓**外**多佔了一圈材質；對的是輪廓**內**有一圈漆 | 平嵌依輪廓裁切，輪廓外就是地 | 案:patina 修訂二；案:coat §7.4 |
| A16 | 作舊模型寫成「琥珀色的漆隨年代變褐」，把金片往褐、往暗乘 | 真漆經年變透變亮 | 年代只讓漆更透、表面更霧 | 記:urushi-clears-with-age；案:finish §15 |
| A17 | 岸與洲浜做成有厚度的浮雕，邊緣有台階的陰影，一片一個平的調子，像墊高的板 | 洲浜是研出，沒有台階；【原話】「平整又大片，不符合肉合研出」 | 粉的厚薄一邊濃一邊淡出，金線收邊 | 案:finish §1、§8 |
| A18 | 山的粉從稜線「垂直往下」畫，山的側邊是一條切線，加實山面之後變硬 | 粉應該沿整條稜最濃，兩側也往內淡出 | 用離稜線的距離決定粉的厚薄，再往山腳與兩端各乘一次漸變 | 案:finish §10.1 |
| A19 | 山腳的鋸齒暗三角，先判斷是烘焙的楔形造成的 | 真因是山與岸底下的地沒有套用和素地同一套疏密，露出的地比外面稀、比外面暗；和岸外一圈暗邊、池邊暗影同一個原因 | 所有「研出在地上」的材質底下就是素地本身；材質性質集中成表，不在多處各判 | 案:finish §9；記:no-coupling-no-magic-numbers |
| A20 | 派出去的包回來，一眼看得出問題，但要改材質才修得了，只能記成「下一包」 | 調外觀是看圖 → 改 → 再看圖的一條鏈，判斷在看圖的一方 | 看得出問題的人就是該動手的人；誰動手照全域合約「跨模型派工」 | 案:finish §2 |
| A21 | 岩為了通過「部件之間要留 12 單位」的測試，被移離它靠著的松根 | 理由因此不成立 | 改測試允許岩與它所屬的部件相接（註明），或拿掉那顆岩 | 案:doha §11.3 |
| A22 | 為了過「輪廓不能有長直線」的檢查，在輪廓上加等距的小波浪 | 檢查只是防呆；等距波浪本身就是複製貼上 | 不為了過檢查改造形或改驗收 | HO §4.5；記:kyoto-art-stays-with-claude（派工單固定條） |
| A23 | 金的落葉嵌片只算鏡面反光，沒被光照到時比底下的金粉還暗，看不見 | 嵌片要有受光的本色 | 嵌片的亮度在任何光位都高於底下的粉 | 案:finish §13 |
| A24 | 池的深淺第一版只在游標光照到時看得見 | 只靠金粉反光的差別，離開光（手機沒有滑鼠）就消失 | 深淺套在整個水面；每次加一張光移開的圖 | HO §4.5；案:finish §13 |
| A25 | 青金的山頭像月亮：日間灰白、夜間一道很亮的白弧 | 青金是偏青的淡金，不是白銀 | 亮度放在金與銀之間，不能是最亮的 | 案:finish §1、§9 |
| A26 | 霞是灰褐的硬邊扁帶 | 金屬太淡、灰銀條佔六成面積、硬邊平片 | 撒出來的一帶金粉，邊是疏密 | 案:finish §11 |
| A27 | 夜間圖案層比濃梨子地還暗 | 夜間主光偏藍偏弱，金被壓成橄欖色 | 夜間主光調暖調強、環境光提高 | 案:finish §13 |
| A28 | 子代理把岩放在不合理的位置、形狀複製貼上，主代理只確認「岩有站在片上」就交給使用者 | 【原話】「一眼可見問題……你自己看不應該就放過喔。」 | 交圖前逐群放大，對每個物件問為什麼 | 記:plate-review-ask-why；案:doha §10、§10.5 |
| A29 | 池邊的岸弧瓣伸進水裡，又被金線描出來 | 【原話】「伸進去的曲線看起來很卡通」 | 岸整圈包在池外，水線就是池的輪廓 | 案:finish §10.2 |
| A30 | 伏見的狐（身體是切銀）被硫化成深橄欖色，像一坨 | 切銀屬於代表白色、該保持淡的那一類 | 銀的類別列進材質表，作舊讀表 | 案:patina 修訂二 |
| A31 | 銀的洲浜先試只在著色器裡把邊改軟：窄了看不出，寬了片縮小又多一圈暗邊 | 研出是粉的厚薄，不是邊緣模糊 | 照金岸的做法從厚薄場畫 | 案:finish §13 |

## B. 工具與流程的坑（任何引擎都會遇到）

| # | 坑 | 做法 | 來源 |
|---|---|---|---|
| B1 | 用 `sed -i` 一類繞過檔案監看的方式改著色器，dev server 沒重載，量到的是舊畫面 | 用編輯工具或整檔寫回；量之前確認截圖是新程式 | HO §4.5；案:patina §9 |
| B2 | 批次拍圖時別的頁面同時佔用 GPU，換場景的按鍵被吃掉，拍到別區、別的日夜 | 拍圖時關掉其他預覽；核對每張輸出的場景與日夜 | HO §4.5 |
| B3 | 桌機截圖的光剛好照在畫面中心，把只靠反光的差別拍得特別明顯 | 每次多拍一張光移到畫面外、一張手機尺寸 | HO §4.5 |
| B4 | 收尾時子代理用太寬的條件結束了 10 個行程 | 只結束自己啟動的行程，記下 PID | HO §4.5 |
| B5 | 量測要用同一個 dev server 與無頭瀏覽器，派給並行代理會量到改到一半的著色器 | 共用量測環境的工作不並行 | 案:patina §9 |
| B6 | 整體的調子數字對小面積的改動不敏感（佔 2% 面積的改動，數字不動） | 小面積的改動靠裁圖放大看 | 案:patina §9 |
| B7 | 截圖取景偏掉、看不到目標，卻被當成「看過」 | 目標要在畫面中央；拍不到就換位置或倍率重拍 | 案:doha §10.5、§11.4 |
| B8 | 參考圖存在本機不提交的資料夾，會被清掉 | 記下公開網址與館藏編號（sources.md） | 記:user-lacquer-collection-album |
| B9 | 相鄰兩種面沒有共用同一個疏密場（或同一個光照、同一個漆層），交界就是一條硬邊或暗帶；同一個原因會在好幾處各冒一次 | 相接的面共用場與材質性質；性質集中一張表（R18） | 案:finish §9、§13 |
