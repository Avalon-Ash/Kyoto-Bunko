# 蒔繪畫法

整理自 Kyoto Bunko 首頁文箱的十一面蒔繪盤（2026-11-13～18）。規則與引擎無關；Kyoto 用 three.js 的對照只放在參考檔最後一節。

## 動手前，對每個東西先問三件事

1. **它在漆的哪裡？** 沉在漆裡（梨子地的片）／研出（洲浜、岸、山的面、平文）／在漆上（高蒔繪、付描、切金、貼金）／嵌入（螺鈿、珊瑚）。這一題決定邊的硬軟、色相、包漿多重。→ [techniques.md](techniques.md) §1
2. **它是哪一層調子？** 地最深、濃梨子地居中、平金與線最亮。三層的順序不能顛倒。→ techniques.md §3
3. **它為什麼在這裡？** 掛在哪個物上、講什麼、尺度對不對、腳有沒有接地。答不出就不放。→ [rules.md](rules.md) R11–R13

## 工作流程

1. **找定標**：技法對初音調度（德川美術館）與使用者的江戶實物；山水建築的布局可看室町的塩山、比良山硯箱與江戶的山水印籠。參考與來源 → [sources.md](sources.md)。
2. **先拍修前、先量修前**，再動手；一次只改一個系統。
3. **審圖**照 [review.md](review.md)：三格並排、逐群放大、光移開也看、分層量調子。
4. 數字達標但看起來不像，連兩輪：是目標設錯了，回頭改計畫，不硬調。
5. 誰動手、派給哪個模型照全域合約「跨模型派工」，本 skill 不重述。

**派工給外部代理時**（子代理、Codex、Gemini 讀不到 `~/.claude/skills/`）：把這一包用得到的段落（相關的 R 條、techniques 的那一節、review §2 的問題）直接貼進派工單，不要只寫 skill 名稱。
