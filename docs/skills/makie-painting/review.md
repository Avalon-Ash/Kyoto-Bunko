# 審圖方法

使用者一眼看得出來的不合理，審查的人沒攔下來，就等於把審查丟給使用者（R13）。交圖前照這份走一遍。標記見 [sources.md](sources.md)。

## 1. 要拍哪些圖

1. **先拍修前、先量修前**，再動手（案:patina §4、ground-tone §5）。
2. **三格並排**：參考圖（同一題材的局部）、修前、修後；放大兩倍，光移開（案:finish §5）。
3. **逐群放大**：每一群（一組岸、一簇岩、一座山、一棟建築腳下）各一張，目標在畫面中央。取景偏掉的不算看過，重拍（案:doha §10.5、§11.4）。
4. **沒有光時也要成立**：多拍一張光移到畫面外，一張手機尺寸。手機沒有滑鼠，游標光要等閒置才出現；桌機截圖的光常剛好照在中心，會把只靠金粉反光的差別拍得特別明顯（HO §4.5）。
5. 日與夜、全新與預設年代（有年代參數時）各看一次；不放大的總覽每區一張，確認沒有哪一區變樣。
6. 截圖前確認是新程式、對的場景（pitfalls B1、B2）。

## 2. 每張圖要問的

**每個物件**
- 它為什麼在這裡？掛在誰身上？說不出就拿掉（R11、R13）。
- 尺度對不對？（岩不比旁邊的樹高；遠的比近的小）腳有沒有接地、有沒有一側懸空？
- 它是立面的畫，還是不知不覺變成俯瞰的土堆（越扁、越圓、越像地形）？（R3）
- 形狀和同類的是不是太像？有沒有大中小的節奏？（R12）

**表面與邊**
- 畫面上有沒有「一圈」或「一條」硬邊、暗線、暗三角？如果有，是光造成的還是畫上去的？（R1、R2）
- 研出的東西（岸、洲浜、山的面、平文）有沒有台階或影子？哪一邊濃、哪一邊化掉？（techniques §1、§4.1）
- 漆下的東西色相是否一致？漆上的是否保持本色、較淡較冷？（R7）
- 有沒有格子、等距重複的紋路？切金是不是成群在邊緣，而不是鋪滿？（R15）
- 銀是不是都還淡？（R8）

**調子**
- 地是不是最深？三層的順序有沒有顛倒（夜間也看）？山、洲浜有沒有比地暗？（R6）
- 青金或銀的山是不是比稜線、建築的平金還亮？（techniques §4.2）
- 盤面是不是太橙褐？先想「漆還不夠透」（R9）。

## 3. 數字

- **分層量調子，不量整張中位數**：用材質遮罩把像素分成地、濃梨子地類、圖案，各取亮度中位數（pitfalls A1）。Kyoto 的門檻：地 27–40、濃梨子地 46–60、圖案 50 以上；不放大時亮度 > 75 的面積 ≤ 6%（案:finish §5，【解讀】）。初音局部的實測是 28／54／62–84（案:doha §13.1，壓縮過的照片，當方向用）。
- 其他可做成腳本的檢查：切金佔坡面積、形狀兩兩相似度、輪廓的最長直線、穿插深度、烘焙時間與換場景的最長幀。
- **數字是門檻，不是終點**：每包都要和參考圖並排看過，寫下看到什麼。數字達標但並排看起來不像，連兩輪 → 目標設錯了，回去改計畫，不硬調（案:patina §5、§6）。
- **不為了過檢查改造形或改驗收**（pitfalls A21、A22）。檢查擋到合理的東西，就改檢查並註明理由。
- 整體數字對小面積的改動不敏感，小面積的改動靠裁圖看（pitfalls B6）。

## 4. 參考圖怎麼看

- 先分「技法」與「該件的意匠、年代風格」，只取技法；年代維持江戶（R17）。
- 再分「經年的樣子」與「保存不良的損傷」，損傷不做（R8）。
- 照片裡的輪廓就是立面輪廓，直接照畫，不換算成俯視（R3）。
- 一張圖不夠就多找幾件；使用者的收藏可以請他拍（R17、sources.md）。

## 5. 交圖時寫什麼

- 每張圖看到什麼（用上面 §2 的問題回答），不寫「更好」「更自然」這種形容詞。
- 自己還不滿意的地方列出來，不藏。
- 數字表（修前、修後、門檻）與產生它的指令；回退方法。
