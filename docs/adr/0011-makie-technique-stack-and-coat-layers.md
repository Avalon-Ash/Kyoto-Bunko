# 0011 蒔繪盤技法分層、透漆包漿與三層亮度結構

狀態：採用
日期：2026-11-16

## 背景

蒔繪盤的地、立體部件、岩、樹與平嵌各自著色，曾出現大面積土坡鋪滿菱形切金格、地上混暗色畫積汙、地與圖案亮度反轉，以及各材質色溫分裂等結構問題。2026-11-16 使用者依技法實例與實物對照，確立技法堆疊表、三層亮度順序、光照遮蔽原則與三類透漆包漿歸屬。

## 決定

- **透漆包漿三類歸屬（材質內計算）**：共用的有色透漆吸收（Beer-Lambert，隨 `?coat=0..1` 與作舊總開關 `?age=0..1` 作用）寫入材質著色器，而非螢幕後製濾鏡。每個材質依與漆面的位置分三類：
  1. **沉在漆裡**（梨子地、刑部梨子地、平目地）：整片受透漆染色。
  2. **研出**（研出蒔繪、肉合研出面、平文、金貝、流水）：面露出維持金屬本色，僅輪廓內側一圈包在漆下，無台階、不外溢（平嵌小物 `reach: 0.5` 依輪廓裁切）。
  3. **在漆上**（高蒔繪、付描、切金、貼金）：僅帶薄層經年包漿。
- **技法堆疊與著色禁則**：大面積土坡、高台與庭面採刑部梨子地或銀平目地，不得整面鋪切金；切金、切銀僅成群散於岩面、樹幹與邊緣點睛（土坡切金上限 5%）；屋面為金粉高蒔繪，貼金限於細部並透出木紋。明暗差由光照與環境光遮蔽產生，禁止往表面混暗色；任何兩種表面相接須有漸變。
- **三層亮度順序與程序生成**：由深到亮固定為「素梨子地（28–38）→ 濃梨子地（48–58）→ 平金與線（60–85）」，不得顛倒；密度場、接觸遮蔽場與作舊紋理皆於執行期程序生成（`bake.js`），不夾帶外部點陣貼圖。

## 放棄的做法

- 以螢幕後製濾鏡實作包漿：使用者指出應直接在材質與網格著色計算（`docs/plans/2026-11-16-coat.md` §1、§3）。
- 在地上以混暗色繪製積汙與腳邊暗線（`patina.md` P2 初版）：已依使用者意見刪除，改為接觸場僅遮蔽環境光（`docs/plans/2026-11-16-patina.md` §9 修訂）。
- 在大面積土坡高台鋪滿 45 度菱形切金格、以無質地單色銀面畫砂庭、將研出與平文歸為整片重染，或以整張截圖中位數作為素的梨子地目標亮度（`docs/plans/2026-11-16-technique-stack.md` §1–§4、`docs/plans/2026-11-16-coat.md` §7.4、`docs/plans/2026-11-16-ground-tone.md` §2）。

## 後果

- 新增盤面材質須明確宣告所屬包漿類別與亮度層級，不得再以混暗色製造陰影或以整面切金填滿大面積。
- 由 `scripts/plate-shot.mjs` 的 `PLATE_TONE=1`（分層亮度）與 `PLATE_KIRI=1`（切金佔比）及 `scripts/plate.test.mjs` 把關。
